Original MIT chess engine using a 0x88 board, iterative deepening, alpha-beta, transpositions, killers, history ordering and check-aware quiescence. Fixed 80,000-node searches; no models or clock-based choices. The readable development source is preserved locally and attached to the private build transcript bundle; main.py is the standalone official LZMA-packed entry.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 -P -s main.py
```
